API de Calendive

Retour à l'application

Documentation interactive de l'API, pour brancher des outils tiers (tableur, automate, site du club…). Pour un outil, créez un jeton d'API dans l'application : menu du compte → Jetons d'API, puis collez-le dans le bouton Authorize ci-dessous pour essayer les routes. Connecté à l'application dans ce navigateur, vous pouvez aussi les essayer directement.

Description OpenAPI brute : /api/openapi.json (à importer dans Postman, Insomnia, un générateur de client…).
