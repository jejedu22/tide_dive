Votre rôle

Le rôle Administration donne, dans votre structure : le choix des créneaux, les réglages, la gestion des membres et de leurs profils, et l'inscription d'autres membres. Tout se trouve dans Administration (en-tête) et sur les pages de recherche et de créneaux choisis. Vous avez aussi tout ce que voit un membre.

Les newsletters demandent le profil Gestionnaire, même pour un administrateur : attribuez-le-vous si besoin (voir Membres).

Premiers pas

  1. Administration → Créneaux : créez vos types de créneaux (« Sortie bateau », « Formation N2 »…) ; sans type, impossible de choisir un créneau.
  2. Réglez le délai de rendez-vous, le port par défaut, les places et les délais d'inscription.
  3. Administration → Utilisateurs : ajoutez vos membres (un par un, ou par import CSV).
  4. Dans la Recherche, choisissez vos premiers créneaux.
  5. Pour voir le courant de vos sites de plongée sur les créneaux choisis (bouton Courants), demandez à l'équipe Calendive de les ajouter (nom et position GPS précise).
  6. Pour les newsletters : connectez votre compte Mailjet et donnez le profil Gestionnaire à qui les rédige.

Réglages de la structure (Administration → Créneaux)

  • Heure de rendez-vous : l'étale moins ce délai, arrondi aux 5 minutes inférieures (étale 9h37, délai 2h15 → RDV 7h20). Un changement s'applique aussi aux créneaux à venir déjà choisis.
  • Port par défaut : proposé d'office aux membres dans la recherche.
  • Horaires de marée : par défaut, les horaires d'api-maree.fr sur le mois à venir et le calcul FES corrigé au-delà. Vous pouvez désactiver l'un ou l'autre pour votre structure seule ; les créneaux à venir sont alors recalés sur les nouveaux horaires.
  • Places par défaut : copiées sur chaque nouveau créneau ; vide : illimité.
  • Délais d'inscription et de désinscription : fermés à partir de N jours avant le créneau ; vide : pas de limite. Un exemple s'affiche sous les champs.
  • Types de créneaux : libellé, couleur, ordre de la liste. Un type utilisé ne se supprime pas : décochez « Proposé » pour le retirer de la liste.

Indisponibilités

Administration → Créneaux → Indisponibilités : déclarez les périodes où la structure ne peut pas sortir (bateau au carénage, congés du club…), pour tous les lieux, avec des heures facultatives et un motif.

  • Pendant une plage, aucun créneau ne peut être choisi, créé ou déplacé ; la recherche marque les étales concernées « Indisponible ».
  • Les créneaux déjà choisis dans la plage restent : ils vous sont listés à l'enregistrement, à vous de les retirer si besoin.

Choisir les créneaux

  • Recherche, colonne Choix : choisissez un type pour retenir l'étale. Elle apparaît aussitôt dans les créneaux choisis ; la croix l'annule.
  • Plusieurs créneaux sur la même étale (deux bateaux) : liste « + Autre… », avec un intitulé pour les distinguer.
  • Choisir les créneaux affichés… : tous les créneaux affichés (filtres compris) d'un coup, avec le même type ; « Annuler ce choix groupé » les retire aussitôt. Filtrez d'abord (ex. étales PM, coefficient ≤ 80).
  • Recherche par hauteur d'eau (si votre structure y a accès) : une plage se choisit de la même façon ; son RDV est le début de la plage.
  • Créneau personnalisé (page Créneaux choisis) : en dehors des étales proposées — lieu (port ou autre lieu), jour ou séjour sur plusieurs jours, heure de RDV, type, intitulé, places.
  • Modifier : type et intitulé de tout créneau ; lieu, jour et heure d'un créneau personnalisé. Places… : nombre de places du créneau. Retirer : supprime le créneau et ses inscriptions.

Places et file d'attente

  • Les N premiers inscrits sont confirmés, les suivants en file d'attente, dans l'ordre d'inscription.
  • Ajouter des places (ou une désinscription) confirme les premiers de la file, prévenus par e-mail ; en retirer remet les derniers inscrits en file d'attente (la fenêtre l'annonce avant d'enregistrer).
  • L'export Excel des créneaux choisis donne les inscrits et la file d'attente.

Membres (Administration → Utilisateurs)

  • Ajouter un utilisateur : prénom, nom, e-mail, rôle (visualisation ou administration), profils. Mot de passe : invitation par e-mail (la personne le choisit) ou mot de passe provisoire à lui transmettre.
  • Importer un fichier CSV (modèle téléchargeable) : analyse ligne par ligne, puis confirmation. 500 comptes au plus par fichier.
  • Inviter un compte existant (qui appartient déjà à une autre structure) par son adresse e-mail : il rejoint la vôtre s'il accepte. Invitation valable 30 jours, annulable.
  • Modifier : rôle et profils (Gestionnaire, Inscriptions). Mot de passe… : renvoyer l'invitation, envoyer un lien de réinitialisation ou définir un mot de passe provisoire.
  • Un compte partagé avec une autre structure : vous gérez son rôle et ses profils chez vous ; son profil et son mot de passe restent à son titulaire. Le retirer ne supprime pas le compte.
  • Vous ne pouvez pas changer votre propre rôle ni supprimer votre propre compte.

Inscrire d'autres membres

Comme le profil Inscriptions : bouton + Inscrire… d'un créneau à venir, et retrait d'une inscription depuis la liste des inscrits. Les délais ne s'appliquent pas. Voir le guide Inscriptions.

Mailjet (newsletters)

Administration → Mailjet : clé API et clé secrète du compte Mailjet de la structure, adresse d'expéditeur validée chez Mailjet. Enregistrer et tester vérifie le tout ; Activer le suivi donne les ouvertures, clics et rebonds dans les rapports. Les clés sont chiffrées et ne sont plus jamais affichées.
