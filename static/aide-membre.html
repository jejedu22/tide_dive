Se connecter

  • Bouton Se connecter en haut à droite : votre identifiant (souvent prenom.nom) ou votre adresse e-mail, et votre mot de passe.
  • Il n'y a pas d'inscription libre : votre compte est créé par un administrateur de votre structure. Vous recevez soit un e-mail d'invitation pour choisir votre mot de passe (lien valable 7 jours), soit un mot de passe provisoire à changer à la première connexion.
  • Mot de passe oublié : lien dans la fenêtre de connexion. Vous recevez un mot de passe provisoire valable une heure ; votre ancien mot de passe reste valable tant que vous ne l'utilisez pas.
  • Un mot de passe compte au moins 12 caractères, avec une minuscule, une majuscule, un chiffre et un caractère spécial ; les règles se cochent pendant la saisie.

Mon compte

  • Mon compte (en-tête) : prénom, nom, adresse e-mail, téléphone, mot de passe. Changer d'adresse demande le mot de passe actuel. Une pastille signale un profil incomplet.
  • Newsletters : case « Recevoir les newsletters de ma structure ». Chaque newsletter contient aussi un lien de désinscription.
  • Plusieurs structures : si votre compte appartient à plusieurs structures, un sélecteur dans l'en-tête permet de changer de structure. Vous y avez un rôle propre à chacune.
  • Invitations : un administrateur d'une autre structure peut vous inviter. Le bouton Invitations apparaît dans l'en-tête : vous rejoignez la structure seulement si vous acceptez.

Chercher des créneaux

Recherche par étale

  • Page Recherche : port, période, phase (pleine mer, basse mer ou les deux), coefficient maximum, marge autour de l'étale, lumière du jour requise. Chercher les créneaux affiche les étales qui conviennent.
  • Chaque ligne donne l'heure de rendez-vous (l'étale moins le délai fixé par votre structure), l'étale, la hauteur d'eau, le coefficient, la fenêtre autour de l'étale et les heures de soleil. Week-ends, jours fériés et vacances scolaires sont signalés.
  • La ligne de titre du tableau permet de filtrer (jour, heure de RDV, PM/BM, hauteur, coefficient, créneaux choisis ou non). Enregistrer mes préférences retient ces réglages pour votre prochaine visite.
  • Exporter en Excel télécharge les créneaux affichés.
  • Les créneaux déjà choisis par votre structure apparaissent grisés, avec leur type.

Recherche par hauteur d'eau

Si votre structure y a accès (lien Hauteurs d'eau dans l'en-tête) : choisissez un port et une hauteur d'eau (par exemple « Mise à l'eau à la cale »). La page liste les plages horaires où l'eau est au-dessus (ou au-dessous) de cette hauteur, avec leur durée et la partie de jour. Une plage marquée limite dépasse à peine la hauteur : ses heures sont incertaines.

Les créneaux de votre structure

  • Page Créneaux choisis : les créneaux retenus par votre structure, en calendrier ou en liste. Filtres par type, « Seulement mes inscriptions », « Afficher les créneaux passés ».
  • Le calendrier montre les jours fériés (en corail), les vacances scolaires (filet violet) et les périodes où la structure est indisponible (hachures). Cliquez sur un jour pour voir ses créneaux.
  • Un créneau peut être une étale (PM / BM), une plage de hauteur d'eau (« ≥ 7,00 m · 09:56 → 14:54 ») ou un créneau personnalisé (« Perso » : sortie à heure fixe, séjour sur plusieurs jours…). L'intitulé distingue plusieurs créneaux le même jour (« Bateau 1 », « Bateau 2 »).

S'inscrire

  • S'inscrire sur un créneau à venir ; Se désinscrire pour annuler. Le nombre d'inscrits s'affiche ; cliquez dessus pour voir qui est inscrit.
  • Places limitées : « 3/8 » indique 3 inscrits confirmés sur 8 places. Un créneau complet propose Rejoindre la file d'attente : votre rang s'affiche. Quand une place se libère, le premier de la file est confirmé et prévenu par e-mail.
  • Délais : votre structure peut fermer les inscriptions et les désinscriptions quelques jours avant le créneau (un cadenas l'indique). Passé ce délai, contactez un administrateur. On peut toujours quitter une file d'attente.
  • Un administrateur ou un encadrant peut aussi vous inscrire : vous recevez alors un e-mail.
